# Strudel Workshop 2025 - Complete Setup Guide

## 🚀 Quick Start

This guide will help you get the **Substrate Prediction via Graph Neural Networks** application up and running from scratch.

## 📋 Prerequisites

### System Requirements

- **macOS** (tested on macOS 13.2.0)
- **Node.js** 18.18.0 or higher (20.0.0+ recommended)
- **Python** 3.11
- **Conda/Miniconda** installed
- **Git** for version control

### Required Software

1. **Node.js & npm** - [Download here](https://nodejs.org/)
2. **Python 3.11** - Install via conda
3. **Conda/Miniconda** - [Download here](https://docs.conda.io/en/latest/miniconda.html)

## 🔧 Installation Steps

### Step 1: Clone and Navigate to Project

```bash
# Clone the repository (if not already done)
git clone <repository-url>
cd saadnaseem-workshop-2025
```

### Step 2: Setup Python Environment

```bash
# Create conda environment for ML models
conda create -n chemprop python=3.11 -y

# Activate the environment
conda activate chemprop

# Navigate to ML directory and install chemprop
cd Strudel_ML_10232025
pip install -e .

# Install additional ML dependencies
pip install rdkit scikit-learn matplotlib seaborn pandas numpy
pip install descriptastorus

# Return to project root
cd ..
```

### Step 3: Setup Backend (Flask API)

```bash
# Navigate to backend directory
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Verify conda environment exists
conda env list | grep chemprop

# Return to project root
cd ..
```

### Step 4: Setup Frontend (React)

```bash
# Install Node.js dependencies
npm install

# Create environment file
echo "VITE_API_URL=http://localhost:5000" > .env.local
```

### Step 5: Verify Installation

```bash
# Check Node.js version
node --version  # Should be 18.18.0+

# Check Python version in conda environment
conda activate chemprop
python --version  # Should be 3.11.x

# Check if chemprop is installed
python -c "import chemprop; print('Chemprop installed successfully')"
```

## 🚀 Running the Application

### Method 1: Two Terminal Windows (Recommended)

**Terminal 1 - Backend Server:**

```bash
cd backend
conda activate chemprop
python run_server.py
```

**Terminal 2 - Frontend Server:**

```bash
npm run dev
```

### Method 2: Single Terminal (Background Process)

```bash
# Start backend in background
cd backend && conda activate chemprop && python run_server.py &

# Start frontend
npm run dev
```

## 🐛 Troubleshooting

### Common Issues

#### 1. "Conda environment 'chemprop' not found"

```bash
# Solution: Create the environment
conda create -n chemprop python=3.11 -y
conda activate chemprop
cd Strudel_ML_10232025
pip install -e .
```

#### 2. "Module not found: chemprop"

```bash
# Solution: Ensure you're in the right environment
conda activate chemprop
cd Strudel_ML_10232025
pip install -e .
```

#### 3. "Failed to fetch" (Frontend can't connect to backend)

```bash
# Check if backend is running
curl http://localhost:5000/api/health

# Check environment variable
cat .env.local
```

#### 4. "CORS error" in browser

- Ensure backend is running on port 5000
- Check CORS configuration in backend/app.py
- Verify frontend is running on allowed port (5173)

#### 5. "Prediction timed out"

- Check if conda environment is activated
- Verify model checkpoints exist in `Strudel_ML_10232025/checkpoints_rdkit/`
- Check system resources (CPU/memory)

## 📊 Application Features

### Frontend Features

- **Molecular Structure Editor**: Draw molecules using Ketcher
- **SMILES Input**: Direct text input for molecular structures
- **Real-time Predictions**: Submit structures for ML predictions
- **Results Display**: Shows prediction probabilities and confidence levels
- **Error Handling**: Comprehensive error messages and validation

### Backend Features

- **REST API**: Flask-based API server
- **SMILES Validation**: Input validation and sanitization
- **ML Integration**: Executes Chemprop prediction scripts
- **CORS Support**: Cross-origin requests enabled
- **Health Monitoring**: Health check endpoint

### ML Model Features

- **Ensemble Predictions**: Uses 10 trained model checkpoints
- **Substrate Utilization**: Predicts Pseudomonas putida substrate utilization
- **Probability Output**: Returns confidence scores (0-1)
- **Batch Processing**: Can handle multiple SMILES inputs
